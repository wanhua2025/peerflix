  Peerflix Server - 快速开始指南
═══════════════════════════════════════════════════════════════

📋 前置要求
───────────────────────────────────────────────────────────────
  ✓ Node.js (版本 6 或更高，推荐 12+)
  ✓ npm (随 Node.js 自动安装)

🚀 快速安装（3 步启动）
───────────────────────────────────────────────────────────────

第 1 步：安装依赖
  npm install

第 2 步：安装构建工具
  npm install -g grunt-cli bower
  bower install

第 3 步：构建并启动
  grunt build
  npm start

成功后访问：http://localhost:9000

═══════════════════════════════════════════════════════════════

⚡ 超快速启动（跳过构建）
───────────────────────────────────────────────────────────────

如果前端资源已经构建好，可以直接：

  npm install
  npm start

访问：http://localhost:9000

═══════════════════════════════════════════════════════════════

🎮 基本使用
───────────────────────────────────────────────────────────────

1. 添加种子
   ├─ 方式 1：输入磁力链接
   ├─ 方式 2：上传 .torrent 文件
   ├─ 方式 3：拖放文件到页面
   └─ 方式 4：输入 InfoHash

2. 播放文件
   └─ 点击文件名 → 使用浏览器或播放器打开

3. 管理下载
   ├─ 暂停/继续：点击暂停按钮
   ├─ 选择文件：勾选复选框
   └─ 删除种子：点击右上角 ❌

═══════════════════════════════════════════════════════════════

⚙️ 常用命令
───────────────────────────────────────────────────────────────

开发模式（自动刷新）
  grunt serve

生产模式
  npm start

自定义端口
  PORT=8080 npm start              # Linux/macOS
  set PORT=8080 && npm start       # Windows

后台运行
  pm2 start server/bin.js --name peerflix-server

📁 配置文件（可选）
───────────────────────────────────────────────────────────────

位置：~/.config/peerflix-server/config.json

示例内容：
{
  "connections": 100,
  "tmp": "D:/Torrents",
  "uploads": 10,
  "downloads": 10
}

🆘 遇到问题？
───────────────────────────────────────────────────────────────

1. 端口被占用
   → PORT=8080 npm start

2. bower install 失败
   → bower install --allow-root

3. 找不到 grunt
   → npm install -g grunt-cli

4. 下载速度慢
   → 检查防火墙，开放 6881 端口

详细帮助请查看：安装使用指南.md
